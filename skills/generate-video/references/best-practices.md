# SaaS Video Best Practices - SaaS 영상 베스트 프랙티스

SaaS 소개 영상의 베스트 프랙티스 모음입니다.
영상의 목적·펀널에 따른 최적 구성을 선택하기 위한 가이드라인을 제공합니다.

---

## 기본 원칙

### 1. 화면보다 먼저"누구의 어떤 고통을 없앨지"를 결정하라

기능 소개가 아니라, 시청자의 고통→해결의 확신을最短で作成する装置として設計한다.

**위험**: 타겟이 모호하면 누구에게도刺さらない

### 2.最初の数秒で余計な儀式を捨てる

冒頭でロゴや演出を長く出すと離脱率が上がるため、すぐに本題へ入る。
音・本題開始の速さを重視。

### 3. 길이는 목적으로 결정하라

일반적으로 길수록 인게이지먼트율은低下하지만, 최적의 길이는 목적에 따라 다릅니다.

| 길이 | 용도 |
|------|------|
| 1-2분 | 冒頭離脱が少ない |
| 5-10분 | 長めの解説 |

**결론**: 장편은冒頭設計が命

### 4. CTA는最後に置かない

시청자의途中離脱を防ぐため、CTAは途中にも置く。

### 5. 보기 쉬운 영상は衛生管理

**우선순위**: 음질 > 화면 가독성 > 템포 > 외관

**중요**: 音が悪いと即離脱

### 6. 자막·트랜스크립트는必須

자막は 필수 요건으로, 자동 생성だけでなく修正도 필요.

### 7. 장편にはチャプター

영상 시청자는跳过り見をしたいので, 챕터（목차）を付ける.

## 펀널별 영상 타입 비교

| 목적（펀널） | 영상 타입 | 길이目安 | 구성 핵심 | 주요 KPI |
|------------------|------------|----------|----------|---------|
| 인지~관심 | 超短尺ティザー | 30〜90초 | 고통→결과（미래）→"続きはここ" | 視聴維持/CTR |
| 관심→검토 | Intro（概要デモ） | 2〜3분 | 1 유즈케이스를最短で完走 | 데모 신청/트라이얼 시작 |
| 검토→확신 | Demo（短尺セールス） | 2〜5분 | 反論の芽を先に潰す |商談化率/답장률 |
| 확신→결정 | Walkthrough / Webinar | 5〜30분 | 実運用の流れ＋証拠 | CVR/문의 |
| 확장·효율화 | ハイブリッドデモ | 録画＋Q&A | 録画で標準化→ライブで個別最適 | 成約率/공수 절감 |
| 지속·활용 | オンボーディング | 30초〜数분（小分け） | 最短のクイックウィン→Aha | Activation/継続率 |
| 지원 | How-to/トラブル | 1〜5분 | 手順을 1본 1목적으로 |문의 절감/자해결률 |

## 카테고리별 가이드

### LP/광고용: 短尺紹介（30〜90秒）

**목적**: 인지~관심 펀널용

**구성アウト라인**:
- 0–5초: 고통 or 원하는 결과
- 5–20초: 대상 사용자와 약속
- 20–60초: 상징 워크플로우 1본
- 60–90초: 다음 수단

**避けるべき落とし穴**: 기능 나열·추상 단어 연발

### 検討向け: 2〜3分 Introデ모

1 유즈케이스를完走させ、専門用語を避けて分解しながら説明.

**推奨事項**:
- 冒頭は短く本題へ
- 一番刺さる1ケースを選ぶ
- 途中CTAも設置

### </minimax:tool_call>向け: 2〜5分デモ

購買決断の次の一手に進めるための短尺セールス向け 영상.

**전략**:
- 反論トップ3を先回りで潰す
- 1動画=1業界／職種

### 決意向け: 15〜30分ウォークスルー

より深い理解と意思決定を促す長尺 영상. 챕터設計必須.

**핵심 포인트**:
- 基本 플로우
- 反論 처리
- 관리/보안 설명

### オンボーディング向け

사용자가最初の 성공体験（Aha）に到達する 설계.

**가이드라인**:
- 1본으로全部教え하지 않기
- 역할별 분기 영상

### サポート／ヘルプ動画

영상을唯一の答えにせず、テキストと併用する.

**필수 요소**:
- 영상＋절차 텍스트
- 자막＋전체 트랜스크립트

## 템플릿

### 90秒刺す紹介テンプレ

**용도**: LP/광고, 인지~관심 펀널

| 시간 | 내용 | 프레임수(30fps) |
|------|------|------------------|
| 0:00–0:05 | 고통 or 원하는 결과 | 0-150 |
| 0:05–0:15 | 대상 사용자와 약속 | 150-450 |
| 0:15–0:55 | 상징 워크플로우 | 450-1650 |
| 0:55–1:10 | 차별화의 근거 | 1650-2100 |
| 1:10–1:30 | CTA | 2100-2700 |

**합계**: 90초 = 2700 프레임

### 3분 Introデ모テンプレ

**용도**: 검토용, 관심→검토 펀널

| 시간 | 내용 |
|------|------|
| 0:00–0:10 | 결론＋고통 |
| 0:10–0:30 | 유즈케이스 선언 |
| 0:30–2:20 | 실제 화면에서完走 |
| 2:20–2:50 | 흔한 불안감 1개解消 |
| 2:50–3:00 | CTA |

### 20분決意向けウォークスルー

**용도**: 확신→결정 펀널

| 시간 | 내용 |
|------|------|
| 0:00–1:00 | 대상과課題 |
| 1:00–8:00 | 基本 플로우 |
| 8:00–12:00 | 反論トップ2 |
| 12:00–15:00 | 관리/보안 |
| 15:00–20:00 | 성공 사례＋CTA |

## 제작 체크리스트

###収録前

- [ ]台本：話すことを削り切る
- [ ]デモ環境：通知オフ、個人情報除去
- [ ]画面：UIの文字が読めるズーム

###収録中

- [ ]音：明瞭さ最優先
- [ ]照明/映り：最低限
- [ ]テンポ：操作を迷う瞬間は全カット

###公開時

- [ ] 자막：반드시品質修正
- [ ] 트랜스크립트：검색과拾い読み用
- [ ] 장편はチャプター必須

## 공통の失敗パターン

| 失敗 | 영향 |
|------|------|
| 누구向けか曖昧 | 누구에게도刺さらない |
| 로고·회사 소개가 김 |冒頭離脱|
| 기능 전부入り | 초점이ぼ김 |
| 자막 없음/雑 | 접근성 저하 |
| 영상만置いて 만족 | 효과 측정 불가 |
| CTA가最後だけ |途中離脱で見られない|

## Harnessでの活用

### 영상 타입 자동 판정

| Harness検出条件 |推奨 영상 타입 | 템플릿 |
|-----------------|----------------|--------------|
| 신규 프로젝트 | LP/광고向け短尺 | 90초 티저 |
| UI 변경 감지 | Intro 데모 | 3분 템플릿 |
| CHANGELOG 업데이트 |릴리스 노트 | Before/After 중시 |
| 대규모 구조 변경 |아키텍처 해설 | 워크스루 |

### 씬 구성 가이드

#### 短尺（30-90秒）の場合

```
HookScene (3초) → ProblemPromise (7초) → WorkflowDemo (40-60초) → Differentiator (10초) → CTA (10초)
```

#### Introデモ（2-3分）の場合

```
Hook (10초) → UseCase宣言 (20초) → 実画面デモ (110초) → 不安解消 (30초) → CTA (10초)
```

#### ウォークスルー（15-30分）の場合

```
対象と課題 (1분) → 基本フロー (7분) → 反論処理 (4분) → 管理/セキュリティ (3분) → 成功事例+CTA (5분)
```

## Remotion実装ルール

### アニメーション

| 규칙 | 이유 |
|--------|-----|
| `useCurrentFrame()`必須 | CSS animations 禁止、Remotion のフレーム制御を使う |
| `spring({ damping: 200 })` |滑らかなモーション|
| `interpolate()` + `extrapolateRight: 'clamp'` |値の暴走防止|
| タイプライター効果は `text.slice(0, charCount)` |文字単位の opacity 変更は非推奨 |

### 音声

| 규칙 | 이유 |
|--------|-----|
| `Audio` は `@remotion/media` から import | `Html5Audio` は非推奨 |
| 音声開始 = 씬開始 + 30f（1초 대기） | スライド変更後に視覚的に落ち着いてから音声開始 |
| 씬 길이 = 30f + 음성 길이 + 20f 여백 | トランジション前に音声終了 |
| `ffprobe` で 음성 길이事前確認 | 씬 설계의 전제 정보 |

### TransitionSeries

| 규칙 | 이유 |
|--------|-----|
| トランジション장은 15f（0.5초）권장 |自然な切り替え|
| 씬 시작 = 前씬 시작 + 前씬 길이 - トランジ션 길이 |オーバーラップを考慮|
| 음성은トランジション開始前に終了させる |切り替え中の音声は違和感|

### 씬 길이 계산 예

```
음성 길이 확인（30fps 환산）:
  hook: 4.0초 = 121 프레임
  problem: 12.0초 = 360 프레임

씬 길이 계산:
  hook: 30(대기) + 121(음성) + 24(여백) = 175 프레임
  problem: 30(대기) + 360(음성) + 25(여백) = 415 프레임

씬 시작 프레임（트랜지션 15f）:
  hook: 0
  problem: 175 - 15 = 160

음성 시작 타이밍:
  hook: 0 + 30 = 30
  problem: 160 + 30 = 190
```
