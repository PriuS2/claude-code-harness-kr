# Image Quality Check - Claude 에 의한 이미지 품질 판정

Nano Banana Pro で生成した画像を Claude が目視判定し、品質を保証します。

---

## 개요

`/generate-video` 의 image-generator.md Step 4에서 실행되는品質判定 로직입니다。
2枚の生成画像を Claude が分析し、採用/不採用を判定します。

## 판정 플로우

```
2枚の画像を受け取り
    │
    ├── [Step 1] 各画像を個別評価
    │   ├─ 基本品質チェック
    │   ├─ 씬適合性チェック
    │   └─ 브랜드整合性チェック
    │
    ├── [Step 2] 判定結果を集計
    │   ├── 両方 OK → Step 3 へ
    │   ├── 1枚 OK → OK を採用
    │   └── 両方 NG → 再生成へ
    │
    └── [Step 3] 2枚から最適なものを選択
        ├─ 比較評価
        └─ 採用画像を決定
```

---

## 판정 기준

### 1. 기본 품질 체크

| 체크 항목 | 합격 기준 | NG 예 |
|-------------|---------|------|
| **선명도** | ぼやけ·노이즈 없음 | 핀트 맞지 않음, 과도한 노이즈 |
| **구도** | 균형이 取れている | 치우침, 짤림, 부자연스러운 배치 |
| **색조** | 자연스럽고 일관성 있음 | 색ムラ, 부자연스러운 채도 |
| **アーティファクト** | 生成ノイズ 없음 | 왜곡, 반복 패턴 |
| **해상도** | 지정 해상도 충족 | 저해상도, 업스케일劣化 |

### 2. 씬 적합성 체크

| 체크 항목 | 합격 기준 | NG 예 |
|-------------|---------|------|
| **주제의 일치** | 프롬프트의 주제를 표현 | 무관한 내용 |
| **스타일의 일치** | 指定スタイルに沿っている | 스타일 불일치 |
| **용도 적합** | 씬의 목적에 맞음 | 영상에 부적합한 구도 |
| **텍스트 품질** | 포함된 경우 읽기 쉬움 | 문자화け, 부자연스러운 텍스트 |

### 3. 브랜드 통합성 체크

| 체크 항목 | 합격 기준 | NG 예 |
|-------------|---------|------|
| **컬러 스키마** | 브랜드 컬러와 조화 | 색 불일치 |
| **톤** | プロフェッショナル | 너무 캐주얼, 저렴함 |
| **일관성** | 他씬と統一感 | 어울리지 않음 |

## 평가 스코어링

### 스코어 정의

| 스코어 | 판정 | 설명 |
|--------|------|------|
| 5 | Excellent | 완벽, 즉시 채용 |
| 4 | Good | 양호, 채용 가능 |
| 3 | Acceptable | 허용 범위, 다른 것이 없으면 채용 |
| 2 | Poor | 문제 있음, 재생성 권장 |
| 1 | Unacceptable | 사용 불가, 반드시 재생성 |

### 채용 임곣값

```
채용 임곣값 = 3（Acceptable 이상）
```

### 2枚 비교時の選択 로직

```
양쪽 다 임곣값 이상の場合:
  → 스코어가 높은 쪽을 채용
  → 同スコアの場合は以下で判断:
     1. 씬 적합성이 높은 쪽
     2. 브렌드整合性が 높은 쪽
     3. 1枚目を採用（기본）
```

## Claude 에 의한 판정 프롬프트

### 이미지 평가 프롬프트

````text
다음 이미지를 평가하세요.

## 평가 대상
- 씬: {scene_name}
- 용도: {scene_purpose}
- 기대 스타일: {expected_style}
- 브랜드 컬러: {brand_colors}

## 평가 기준
1. 基本品質（선명도, 구도, 색조, 아티팩트）
2. 씬 적합성（주제, 스타일, 용도）
3. 브렌드 통합성（컬러, 톤, 일관성）

## 출력 형식
```json
{
  "score": 1-5,
  "verdict": "OK" | "NG",
  "strengths": ["좋은 점1", "좋은 점2"],
  "issues": ["문제점1", "문제점2"],
  "improvement_suggestions": ["개선안1", "개선안2"]
}
```
````

### 2枚比較 프롬프트

````text
다음 2枚の画像を比較し、より適切な方を選択してください。

## 평가 대상
- 씬: {scene_name}
- 용도: {scene_purpose}

## 이미지 A 의 평가
{image_a_evaluation}

## 이미지 B 의 평가
{image_b_evaluation}

## 출력 형식
```json
{
  "selected": "A" | "B",
  "reason": "선택 이유",
  "comparison_notes": "비교의 상세"
}
```
````

## NG時の再生成 지시

### 개선 프롬프트 생성

```
이전 이미지가 채택되지 않았습니다.

## 문제점
{issues}

## 개선안
{improvement_suggestions}

## 수정 프롬프트
다음 점을 개선한 프롬프트를 생성하세요:
1. {improvement_1}
2. {improvement_2}
```

### 재생성시의 조정 전략

| 문제 카테고리 | 조정 전략 |
|-------------|---------|
| 구도의 문제 | `centered composition`, `balanced layout` 을 추가 |
| 색의 문제 | 구체적 색 지정（HEX）을 추가 |
| 스타일 불일치 | 스타일 지정을 보다 구체적으로 |
| 텍스트 품질 | `no text` 을 추가, 나중에 오버레이 |
| 품질 저하 | `high quality`, `4K`, `detailed` 을 추가 |

## 실행 예

### Read 도구로 이미지 읽기

```
Claude 가 Read 도구로 이미지를 읽음:

Read:
  file_path: "out/assets/generated/intro_1.png"

Read:
  file_path: "out/assets/generated/intro_2.png"
```

### 평가 실행

```
이미지를 평가 중...

📊 평가 결과:

| 이미지 | 스코어 | 판정 | 주요 평가 |
|------|--------|------|---------|
| intro_1 | 4/5 | ✅ OK | 구도 양호, 색조 통일 |
| intro_2 | 3/5 | ✅ OK | 다소 어두움, 구도에 치우침 |

🎯 선택: intro_1
이유: 전체적 균형과 밝음이 뛰어남
```

### NG時の 출력 예

```
📊 평가 결과:

| 이미지 | 스코어 | 판정 | 주요 문제 |
|------|--------|------|---------|
| cta_1 | 2/5 | ❌ NG | 텍스트가崩れている |
| cta_2 | 2/5 | ❌ NG | 색이 너무 어두움 |

⚠️ 양쪽 이미지 모두 기준을 충족하지 못함

개선안:
1. 프로MPT에 `no text` 를 추가（텍스트는 나중에 오버레이）
2. `bright colors`, `light background` 를 추가

재생성을 실행합니다... (시도 2/3)
```

## 판정의 바이패스

### 강제 채용

```
사용자가「이 이미지로 좋다」고 지정한 경우:
→ 品質判定をスキップして採用
```

### 임곣값 조정

```
사용자가「더 엄격하게」지정한 경우:
→ 採用 임곣값을 4로 인상

사용자가「일단대로」지정한 경우:
→ 採用 임곣값을 2로 인하
```
