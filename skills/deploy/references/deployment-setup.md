# Deploy Setup Skill

Vercel/Netlifyへの 배포를 자동화하는 스킬.

---

##トリガーフレーズ

- 「배포할 수 있게 해줘」
- 「Vercel에내고 싶다」
- 「Netlify에 배포하고 싶다」
- 「프로덕션 환경을 설정해줘」

---

## 기능

- Vercel/Netlify 프로젝트 생성 가이드
- 환경 변수의 설정 가이드
- GitHub Actionsによる 자동 배포
- 프리뷰 배포（Pull Request）

---

## 실행 흐름

1. 프로젝트 구성을 확인
2. Vercel 또는 Netlifyを選択
3. 설정 파일 생성（vercel.json / netlify.toml）
4. 환경 변수의 설정을 가이드
5. 배포 검증
